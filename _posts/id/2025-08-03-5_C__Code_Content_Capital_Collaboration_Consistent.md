# 5 C: Code, Content, Capital, Collaboration, Consistent

Saya sangat beruntung dan bersyukur, bahwa saya hidup di zaman AI seperti sekarang ini.<br/>
Bagi Programmer seperti saya, terlalu banyak ~~Godaan~~ ujian:

- oprek sana, oprek sini
- Research ini, Research itu
- Test product X, Y, Z
- …

pada akhirnya menjadi: **Tidak Produktif**

Saya memerlukan suatu pegangan.

**5 C: Code, Content, Capital, Collaboration, Consistent**

## Kata ke-1: Code

Saya letakkan kata `Code` sebagai kata pertama:

- sebagai seorang _Programmer_, ini sudah menjadi refleks
- saya bukan memandang:
    - bahwa `Code` ini **Paling Penting**
    - atau kata lain **Tidak Penting**
- saya hanya berusaha untuk:
    - mulai dari hal Kecil
    - mulai dari hal Sederhana
	- mulai dari hal yang saya Bisa

walaupun tentu saja, ada bagian Design / Document, seperti saya jelaskan pada artikel [Document Driven Development](/id/Document_Driven_Development/)

## Kata ke-2: Content

Saya letakkan kata `Content` sebagai kata kedua:

- ini saya maksudkan dalam bentuk Article dan/atau Video
- melalui content, saya bisa bebas berekspresi {saya bisa menulis dengan _my own writing style_}

Pada artikel [Menulis untuk 'Future of Me'](/id/Menulis-untuk-Future-of-Me/), saya ceritakan pada bagian:

### Belajar banyak dari Internet, now share my own

Saya belajar banyak hal dari Internet {tulisan / video yang dibuat oleh banyak orang}.<br/>
Saya fikir, sudah saatnya saya mulai _share_ tulisan ke publik.

### Tulisan yang bermanfaat

- bermanfaat bagi saya sendiri, di "Masa Datang"
- bermanfaat bagi Orang Lain {semoga}

## Kata ke-3: Capital

Saya bukanlah `Programmer yang Baik/Bagus` {if I am, then I will work for Google, Microsoft, … TopTal}  
Tetapi, saya ~~sangat~~ cukup menyukai topik _Software Engineering_.

Saya letakkan kata `Capital` sebagai kata ketiga, sebagai _reminder_ bagi saya:

- semua aktivitas ini memerlukan _Capital_ {baca: _Money_}
- bahwa _ignore_ hal tersebut, akan mempersulit saya

```
Code → butuh waktu → waktu adalah uang
Content → butuh energi → energi butuh bahan bakar
Collaboration → butuh reputasi → reputasi dibangun dari karya
✅ Capital bukan tujuan — tapi sangat penting agar semua C lainnya bisa berjalan
```

## Kata ke-4: Collaboration

Saya letakkan kata `Collaboration` sebagai kata keempat {bukan di posisi ke-1, 2 ataupun 3}:

- _Collaboration / Networking_ == sangat penting, tetapi sebaiknya semua dimulai dari _Faktor Internal_ terlebih dahulu
- _Faktor Internal_ yang solid/matang, dibentuk melalui proses ke-1 dan ke-2 di atas
- jika langsung lompat ke _Collaboration_, tanpa _Fondasi Internal_ yang solid/matang ? maka akan mudah "Patah"

```
bukan saya tidak memandang Penting -- kata ini, tetapi:
❌ Zero Collaboration is far better than Toxic Collaboration
```

## Kata ke-5: Consistent

Pada akhirnya, _Consistent is the key._<br/>
Semua C di atas — tidak ada artinya tanpa kata _Consistent_.

Tentu saja, masing-masing mempunyai _Challenge_ tersendiri.<br/>
Untuk _Content_, saya sudah bahas pada artikel [Multi Layer saat membuat Content {tulisan, video, ...}](/id/Multi-Layer-membuat-Content__tulisan_video/)
