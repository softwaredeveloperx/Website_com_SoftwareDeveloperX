# Refine: Document

## Context
- This is a **Generic Template**
- Used to review any {.MD file}

## Situation
- I upload a {.MD file}
- please review the {.MD file}

## Plan
- that {.MD file} is a _Design - Business Process_
- a _Specification Document_
- as a reference for _Development_

## Request

- is everything Ok?
- is there any InComplete statement?
- is there anything Ambiguous?
- Consistency → are there any inconsistent terms across sections?
- Missing section → is there any important section that is missing?

## Expected Result
- please write the Review result as a new .MD file

## Note

Too Few vs Too Much

```
❌ Too Few   → Incomplete, not useful
❌ Too Much  → Overwhelmed, information overload
✅ Pragmatic
```

You need to find the _sweet spot_ -- the one that is "just right".
